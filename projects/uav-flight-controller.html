Project Overview

Custom-built quadcopter running a high-frequency bare-metal flight loop on a 600MHz ARM Cortex-M7 Teensy 4.0 microcontroller. Designed to execute precise attitude stabilization and altitude hold via sensor fusion.

Technical Features

  • 1 kHz Deterministic Loop: Uses hardware timers to read registers, update Kalman state vectors, calculate PID outputs, and output DShot motor signals with microsecond timing.
  • Sensor Filtering: Configured the onboard BMI323 IMU digital filters (10 Hz low-pass) to remove high-frequency structural vibration and motor harmonic noise.
  • 2-State Kalman Filter: Fuses vertical accelerometer integrals with barometer readings to produce accurate vertical velocity and altitude state estimates.

Sample PID Flight Loop

void loop_1000Hz() {
    read_sensors_raw();
    kalman_filter_update(raw_accel, raw_baro);
    
    float roll_output  = pid_calculate(&pid_roll,  target_roll,  current_roll);
    float pitch_output = pid_calculate(&pid_pitch, target_pitch, current_pitch);
    float yaw_output   = pid_calculate(&pid_yaw,   target_yaw,   current_yaw);
    
    mix_and_write_motor_dshot(roll_output, pitch_output, yaw_output);
}
