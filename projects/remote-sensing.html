Municipal Canopy Engine & Satellite Viewer

Timeline: Aug 2025 – Dec 2025 | Tech: Python, FastAPI, Rasterio, PostGIS, STAC, React, TypeScript

Project Overview

An on-demand geospatial pipeline and interactive analysis dashboard that computes high-resolution vegetative health and municipal canopy shifts across multi-year temporal baselines (2020 vs. 2024). The engine queries European Space Agency (ESA) Sentinel-2 Level-2A surface reflectance data on the fly, isolates official administrative boundaries, and calculates true vegetative presence within seconds.

Key Architectural Components

  • Asynchronous STAC Pipeline: Concurrently queries Microsoft Planetary Computer APIs to discover, sign, and ingest cloud-optimized GeoTIFF (COG) band assets (B04, B08, SCL) across multi-year temporal windows.
  • Radiometric Baseline Harmonization: Normalizes digital numbers and compensates for the ESA Processing Baseline 04.00 offset (−1000 DN) to eliminate false sensor delta artifacts across 2020–2024 datasets.
  • Sub-Window GDAL Streaming: Bypasses heavyweight array loading by executing parallelized HTTP/2 range-requests via Rasterio and ThreadPools, pulling only the exact bounding-box pixels required for the target municipal extent.
  • Vector Polygon Masking: Integrates OpenStreetMap boundary GeoJSONs with OpenCV and PostGIS to rasterize official city perimeters, isolating municipal land from peripheral unincorporated terrain and open water.
  • Interactive Split UI: Modern React/TypeScript dashboard featuring a real-time comparison scrubber, locked aspect-ratio viewing, and categorized spectral color-ramping.
