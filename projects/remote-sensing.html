Project Overview

A high-throughput satellite data pipeline and interactive visualization dashboard for environmental change and deforestation trend modeling across multi-year temporal windows.

Key Architectural Components

  • STAC Query Ingestion: Programmatic discovery across multi-year temporal windows via Microsoft Planetary Computer STAC APIs.
  • Distributed Array Reductions: Multi-threaded Dask computation calculating NDVI and localized delta metrics on 50GB+ unstructured arrays.
  • Decoupled Delivery: Asynchronous FastAPI backend delivering compressed raster tiles to an interactive TypeScript frontend.
